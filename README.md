# 团播多平台直播墙

在一个桌面窗口同时观看多个抖音或小红书直播间，支持名称搜索、在线人数、独占音频、清晰度选择和自动录制。

## 下载与更新

在 [GitHub Releases](https://github.com/JinHe9527/douyin-live-wall/releases/latest) 下载完整安装包。Windows 64 位选择 `win-x64.exe`；macOS 按芯片选择 `mac-arm64.dmg` 或 `mac-x64.dmg`。

已安装客户端可在「直播间管理 / 设置 → 检查更新」获取新版。Windows 下载完成后提示重启安装；macOS 提供新版下载入口。安装包未配置商业代码签名。

## 使用

- 顶部选择「抖音」或「小红书」。各平台独立保存直播间库、上墙列表、布局、画质和录制设置。
- 输入直播间或主播名称，回车后点击结果里的「添加」即可上墙。小红书同时查询笔记直播卡片和主播用户，支持 X-RAY 等用户结果中的直播入口。
- 也可以粘贴直播分享链接或房间号。抖音另支持主播主页；主页会解析当前直播入口。
- 需要登录时，在设置中点击对应平台的登录按钮，在官方窗口完成登录后重试。
- 每格显示名字与人数。小红书优先显示官方实时数据中的具体在线人数；仅有区间或累计观看数据时按原口径标注。
- 在直播间管理里可分组、上墙或下墙，列数可选自动、2、3、4。
- 单格支持独占音频、刷新、全屏和官方详情。抖音保留弹幕、礼物与战况叠层；小红书暂未接入这些叠层。
- 自动录制默认关闭；可按房间启用并设置时长，文件保存在系统视频目录下对应平台文件夹。

搜索、播放与人数受平台登录状态、网络和官方页面结构影响。没有获取到可靠数据时显示提示，不使用点赞数替代在线人数。

## 源码与构建

```bash
npm ci
npm start
npm run test:mini
npm run dist:win
npm run dist:mac
```

构建文件位于 `dist-mini/`。推送与 package.json 版本一致的 `v*` 标签后，GitHub Actions 在 Windows 和 macOS 上测试并构建，两个平台成功且更新文件校验通过后才一起发布。

技术：Electron、mpegts.js；复用官方页面获取直播数据，使用每个平台各自的登录会话。保留抖音多 CDN 换线与重连能力。
