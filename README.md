# 抖音多宫格直播墙

多个抖音直播间**同时观看**的桌面应用。打开就出画面——不撞验证码、不用单独登录。

专为团播视觉总控/运营盯场设计：一屏同时盯多个直播间，谁在干嘛一目了然。

## 为什么不用网页/旧方案

抖音网页端一个号同时只能看一个直播间，多开会互相挤掉，而且整页加载频繁撞滑块验证码、要登录。

本应用换了思路：直接解析直播间的 **flv 拉流地址**（CDN 流），用 [mpegts.js](https://github.com/xqq/mpegts.js) 在每个格子里直接播。所以：

- ✅ 多个直播间真正**同时**出画面，互不挤掉
- ✅ **不撞验证码、不用登录**（直播间直链只需公开的 ttwid）
- ✅ 每格只是一个轻量视频，CPU/内存远低于"每格开一张网页"

## 使用

下载安装包打开即可。首次打开自带几个默认直播间，开箱即看。

- **加直播间**：顶部粘贴`直播间链接 / 房间号`回车；或点右上角 ⚙「直播间管理」加入库
- **分组管理**：在「直播间管理」里给每个直播间填分组（如「宇宙」），自动按组归类
- **上墙/下墙**：管理面板里勾选即上墙观看，取消即下墙
- **列数**：顶部切换 自动 / 2 / 3 / 4 列
- **单格操作**（悬停显示）：独占音频 / 刷新 / 全屏 / 下墙
- **主播主页链接**：库里也可放主播主页（`douyin.com/user/...`），未开播显示「未开播」，**开播自动上画面**（需登录态）

支持的链接形态：`live.douyin.com/房间号`、`douyin.com/follow/live/房间号`、纯房间号、主播主页链接。

## 从源码运行 / 打包

```bash
npm install
npm start            # 本地运行
npm run dist:mac     # 打 macOS (arm64) 安装包，产物在 dist-mini/
```

## macOS 首次打开提示

安装包未做苹果签名（内部工具）。若提示"已损坏/无法验证开发者"，在终端执行一次：

```bash
xattr -cr "/Applications/抖音多宫格直播墙.app"
```

或：右键 App →「打开」→ 再点「打开」。

## 技术

Electron + mpegts.js（flv 直播流）。取流走抖音 `webcast/room/web/enter` 接口，主页链接走页面解析兜底。仅供内部学习与监看使用。
