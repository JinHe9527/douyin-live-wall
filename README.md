# 团播多平台直播墙

在一个桌面窗口同时观看多个抖音或小红书直播间，支持名称搜索、在线人数、独占音频、清晰度选择和自动录制。

## 下载与更新

在 [GitHub Releases](https://github.com/JinHe9527/douyin-live-wall/releases/latest) 下载完整安装包。Windows 64 位选择 `win-x64.exe`；macOS 按芯片选择 `mac-arm64.dmg` 或 `mac-x64.dmg`。

已安装客户端可在「直播间管理 / 设置 → 检查更新」获取新版。Windows 下载完成后提示重启安装；macOS 提供新版下载入口。安装包未配置商业代码签名。

## 使用

- 顶部选择「抖音」或「小红书」。各平台独立保存直播间库、上墙列表、布局、画质和录制设置。
- 默认优先使用独立游客会话观看，不需要先登录。粘贴当前直播分享链接或房间号即可添加；游客会话不复制账号 Cookie，也不会退出已登录的账号。
- 输入直播间或主播名称，回车后点击结果里的「添加」即可上墙。名称搜索可能需要登录，搜索受限时可点击「粘贴直播链接观看」。小红书同时查询笔记直播卡片和主播用户，支持 X-RAY 等用户结果中的直播入口。
- 也可以粘贴直播分享链接或房间号。抖音另支持主播主页；主页会解析当前直播入口。
- 游客播放优先读取官方分享页，有流时直接起播；小红书分享页缺流时继续尝试官方桌面页面。已有正常登录的账号可作为备用。平台明确要求登录或验证的房间仍可能无法游客观看。
- 每格显示名字与人数。小红书优先显示官方实时数据中的具体在线人数；仅有区间或累计观看数据时按原口径标注。
- 小红书自动/流畅模式会优先使用官方桌面播放器提供的低码率线路，保留原画与备用线路；旧场次结束后自动查找同一主播的新场次，未开播房间继续后台检查。
- 在直播间管理里可分组、上墙或下墙；宫格根据窗口大小和房间数量自动排列。
- 顶栏直接显示登录状态；「常显信息」展示当前播放视频的实时分辨率，随画质变化更新。
- 小红书「常显信息」同时展示场观（平台累计看过人数）和累计观看人次，与在线人数分别标注；平台推送有更新时同步，否则约每 90 秒刷新。
- 单格支持独占音频、刷新、全屏和官方详情。抖音保留弹幕、礼物与战况叠层；小红书暂未接入这些叠层。
- 自动录制默认关闭；可按房间启用并设置时长，文件保存在系统视频目录下对应平台文件夹。

搜索、播放与人数受平台登录状态、网络和官方页面结构影响。没有获取到可靠数据时显示提示，不使用点赞数替代在线人数。

## 源码与构建

```bash
npm ci
npm start
npm run test:mini
npm run dist:win
npm run dist:mac
```

构建文件位于 `dist-mini/`。推送与 package.json 版本一致的 `v*` 标签后，GitHub Actions 在 Windows 和 macOS 上测试并构建，两个平台成功且更新文件校验通过后才一起发布。

技术：Electron、mpegts.js；复用官方页面获取直播数据，每个平台的游客会话与账号会话隔离。保留抖音多 CDN 换线与重连能力。

游客联网验证：`node scripts/smoke-guest.cjs <douyin|xiaohongshu> <直播链接>`。使用全新内存会话获取直播流并检查 FLV 文件头；`--saved` 验证本机房间库各平台的前三个房间，不输出 Cookie 或签名流地址。

实际播放器验证：`node scripts/smoke-app.cjs <douyin|xiaohongshu> <直播链接>`，在临时空配置中启动隐藏的实际直播墙，检查视频尺寸、解码帧及播放进度，不修改本机房间库。
